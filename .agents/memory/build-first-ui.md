---
name: Build-first UI iteration
description: User preference for implementing visual changes directly in the Experiences.fun mobile app.
---

For UI changes to existing Experiences.fun mobile screens, implement in the mobile app and render the running app preview directly. Do not route the work through Canvas or an isolated design mockup unless the user asks for that.

When the user supplies a materially different visual reference, make the corresponding structural layout change rather than only adjusting spacing or decoration.

**Why:** The user explicitly asked for direct build rendering after a previous iteration still looked too similar to the original screen.

**How to apply:** Update the existing mobile screen, present the updated app preview, and verify the rendered result at relevant phone sizes.
