---
name: Experience XP league events
description: Preserve award-time categories and count independently verified milestone awards.
---

Verified Experience and milestone XP awards must retain the Experience category in effect when the award is created. League scoring must read the stored award category, not infer it from the Experience's current category.

Verified milestone awards count from the milestone submission's own verification, even while the parent participation is still in progress. Completion XP still requires a verified participation.

**Why:** Later Experience edits must not reclassify old league credit, and milestone XP can be earned before the whole participation is complete.

**How to apply:** When changing award creation or league scoring, preserve the category snapshot and validate each award against its own verified source. Legacy awards without snapshots can only be backfilled from the source's current saved category.
