---
name: Telegram qualifying message tracking
description: The user's boundaries for counting XP-eligible messages in linked Telegram groups.
---

Count eligible messages from Telegram updates received after the bot is linked to the group. Existing contribution records may backfill only the qualifying history they actually contain; do not import or invent older chat history. Use the product's existing qualification rule, independently of whether XP is awarded because of caps or duplicate checks.

**Why:** The user explicitly required Telegram's existing group data and counts only after bot setup, with no imported history.

**How to apply:** When changing group message tracking or reporting, keep raw observed-message totals distinct from XP-qualifying counts, and state the bot-link tracking boundary clearly.
