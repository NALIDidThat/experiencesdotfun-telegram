32. LEADERBOARD SCORING
==================================================

Use a dedicated Memory Game score.

Do NOT simply use the user's total Experiences.fun XP balance.

Recommended score:

Memory Score = total XP earned from successfully completed Memory Game levels

Since each level awards 5 XP:

1 completed level = 5 Memory Score

7 completed levels = 35 Memory Score

However, also store additional performance metrics so the leaderboard can later support more sophisticated scoring.

Store:

memoryXp
levelsCompleted
highestLevel
gamesCompleted
bestRun
fastestRecall
accuracy
totalAttempts


==================================================
33. LEADERBOARD TIE BREAKING
==================================================

If two players have the same Memory Score, rank them using:

1. Highest level completed
2. Highest accuracy
3. Fewest failed attempts
4. Fastest completion time
5. Earlier achievement timestamp

This ensures that equal XP does not always result in an arbitrary ranking.

44. LEADERBOARD MOTIVATION
==================================================

The leaderboard should encourage healthy competition.

Use language such as:

"You're 15 XP away from #200"

or:

"3 more levels to pass Alex"

Avoid manipulative language such as:

"YOU'RE FALLING BEHIND!"

The experience should encourage improvement rather than create anxiety.


==================================================
45. DATA INTEGRITY
==================================================

Leaderboard scores MUST be calculated from verified game completions.

Never allow the client to submit:

"Give me 5 XP"

Instead:

Client submits:

level completion attempt

Server validates:

- User identity
- Game state
- Level
- Attempt
- Correct answers
- Completion status
- Whether XP was already awarded

Server then:

1. Records completion.
2. Awards 5 XP.
3. Updates MemoryGameStats.
4. Recalculates leaderboard position.


==================================================
46. ANTI-CHEAT FOUNDATION
==================================================

The initial version does not need sophisticated anti-cheat.

However, architect the system so obvious abuse can be detected.

Track:

- Impossible completion times
- Excessive level completion frequency
- Duplicate attempts
- Duplicate XP events
- Suspicious client requests

Never trust:

- Client-side score
- Client-side XP
- Client-side level completion
- Client-side leaderboard position

48. IMPORTANT PRODUCT PRINCIPLE
==================================================

The leaderboard is part of the game's progression loop.

The complete loop is:

MEMORIZE
↓
PLAY
↓
COMPLETE LEVEL
↓
+5 XP
↓
RANK UP
↓
COMPARE WITH FRIENDS
↓
COMPARE GLOBALLY
↓
PLAY AGAIN

The leaderboard should create a reason to improve without making the game feel competitive by default.

The primary experience remains:

Memory → Mastery → XP → Reputation

The leaderboard is the social layer around that loop.
