You are working on the current Experiences.fun application.

Your task is to implement a complete ACCOUNTABILITY PARTNER SYSTEM.

This system should allow two or more people to voluntarily become accountability partners, define shared goals/experiences, see each other's progress, send encouragement, receive milestone updates, and interact with the system through Telegram.

IMPORTANT:
This is NOT a generic friend system.

The purpose of accountability partners inside Experiences.fun is to help people actually participate in experiences, complete goals, maintain consistency, and contribute to their communities.

The system should connect:

USER
↓
GOALS / EXPERIENCES
↓
ACCOUNTABILITY PARTNER
↓
PROGRESS
↓
VERIFICATION / CHECK-INS
↓
NOTIFICATIONS
↓
TELEGRAM
↓
XP / REPUTATION
↓
SOCIAL FEED

==================================================
1. PRODUCT THESIS
==================================================

The core idea:

"People are more likely to follow through when someone else can see whether they did."

Experiences.fun should turn accountability into a native part of the product.

An accountability partner should not just be someone you can message.

They should be able to:

- See agreed goals
- See upcoming commitments
- See progress
- See completed experiences
- Receive milestone notifications
- Encourage the other person
- Check in with them
- Celebrate wins
- Notice missed commitments
- Help keep momentum

The relationship should be based on ACTION.

Not empty social engagement.

45. COMPLETE USER JOURNEY
==================================================

Test this exact flow.

USER A:

1. Opens Experiences.fun
2. Opens Accountability
3. Selects "Add Partner"
4. Invites USER B
5. USER B receives invitation
6. USER B accepts
7. Partnership becomes active
8. USER A creates commitment:
   "Attend Photography Workshop"
9. USER B receives notification
10. USER B accepts
11. Both see commitment
12. USER B attends/completes experience
13. Experience completion automatically updates commitment
14. USER A receives notification
15. USER B receives XP
16. Partner can congratulate USER B
17. Activity appears in partnership timeline
18. Public social feed event appears only if permitted

THEN TEST TELEGRAM:

1. USER B links Telegram
2. Telegram receives confirmation
3. Next commitment reminder is sent
4. User clicks:
   [✅ Completed]
5. Telegram webhook processes action
6. Experiences.fun updates commitment
7. XP/reputation updates
8. Partner notification is triggered
9. Telegram confirmation is sent
10. App reflects the same state

There must be ONE source of truth.

If the app says completed and Telegram says incomplete, the system is broken.
